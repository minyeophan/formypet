# PRD: 펫일기 (Petyilgi)

## 목표
모든 종류의 반려동물(강아지, 고양이, 앵무새, 햄스터, 거북이 등)의 일상 활동, 건강, 성장을 기록하고 반려인 커뮤니티와 연결하는 앱

## 사용자
반려동물을 키우는 누구나 — 종류 제한 없음. 첫 반려동물을 키우는 입문자부터 여러 마리를 키우는 숙련자까지.

## 핵심 기능
1. **반려동물 프로필** — 이름, 종류(종 선택), 생일 등록. D+day 자동 계산. 여러 마리 등록 및 전환.
2. **활동 기록** — 식사, 산책, 건강검진, 체중 측정 등 빠른 기록. 날짜별 달력 시각화. 활동/건강/성장 탭 분류.
3. **커뮤니티** — 반려인 피드. 사진+텍스트 포스트. 좋아요.

## MVP 제외 사항
- 백엔드 / 사용자 인증 (로컬 AsyncStorage만 사용)
- 푸시 알림
- 다이렉트 메시지 / 채팅
- 커뮤니티 검색, 해시태그, 팔로우
- 사진 업로드 (커뮤니티 포스트는 텍스트만)
- 반려동물 프로필 사진
