# 소식 게시글 운영

소식은 기존 게시글 작성 화면에서 운영자만 커뮤니티 `NEWS` 카테고리를 선택해 작성하는 실제 게시글이다. 별도 작성·목록·상세 화면을 추가하지 않고 기존 게시글 화면을 사용한다. 일반 사용자는 기존 소식 목록·상세를 볼 수 있고, 관리자만 소식을 작성·수정할 수 있다. `EVENT`(이벤트)는 이번 제한 대상이 아니다.

## 권한

- V27 migration이 `users.role`을 추가한다. 기존 계정과 신규 일반·카카오 계정의 기본값은 `USER`다.
- `/api/v1/users/me`가 `role`을 반환하며 앱은 `ADMIN`에게만 글쓰기 게시판 선택에 소식을 표시한다.
- 서버는 게시글 생성·수정 시 DB의 사용자 권한을 확인한다. 일반 글을 소식으로 바꾸는 요청과 권한이 해제된 사용자가 기존 소식을 수정하는 요청도 차단한다.
- 회원가입·프로필 변경·게시글 요청에 임의로 `role`을 넣어도 관리자 권한을 부여하지 않는다. 관리자라도 다른 사람이 작성한 글을 수정하는 권한은 추가하지 않았다.

## 서버 연동 단계의 남은 작업

1. 운영에 사용할 계정 하나를 만들고 소유자를 확인한다. 이번 작업에서는 실제 계정이나 비밀번호를 만들지 않았다.
2. 운영 DB 담당자가 해당 계정의 정확한 ID를 확인한 뒤 `role`을 `ADMIN`으로 지정한다. 일반 앱에 권한 승격 API를 제공하지 않는다.
3. 프로필을 새로 불러오거나 다시 로그인해 소식 작성 선택지를 확인한다.
4. 홈의 고정 뉴스 카드를 `GET /api/v1/posts?category=NEWS` 결과에 연결하고, 카드 클릭은 기존 게시글 상세로 연결한다. 모두 보기는 소식 카테고리 목록을 사용한다.
5. 실제 계정으로 일반 사용자의 소식 작성 거절, 관리자의 작성·수정, 일반 사용자의 열람을 확인한다.

관리자 지정은 운영 데이터 변경이므로 여기에는 계정 ID·로그인 정보·자동 승격 코드를 포함하지 않았다.
