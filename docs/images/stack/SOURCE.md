# 기술 로고 출처

[Devicon](https://github.com/devicons/devicon) 공개 SVG를 사용합니다.

다운로드 기준 커밋: `7330accdbc47e2dc0c19789a48533c4a3c50fe58`

카드 규격: 120 × 136. 로고 영역: 64 × 64. 이름 중심선: y=112. 흰 배경과 동일한 테두리, 여백을 사용하며 원본 로고 비율을 유지합니다.
